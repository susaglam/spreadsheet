Spreadsheet Dashboard for Inventory
===================================

|badge1| |badge2| |badge3|

Pre-built inventory and stock movement dashboard.

**Table of contents**

.. contents::
   :local:

Features
========

* Stock movement scorecards
* Monthly movement trend
* Recent transfers list
* Warehouse and product category filters

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Auto-installs when ``stock`` module is present.

Dependencies
============

* ``spreadsheet_dashboard``
* ``stock``

Known issues / Roadmap
======================

* Stock valuation trends
* Low stock alerts

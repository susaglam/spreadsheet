Quote-to-Order Conversion Dashboard
===================================

|badge1| |badge2| |badge3|

Pre-built dashboard showing quote-to-order conversion rates.

**Table of contents**

.. contents::
   :local:

Features
========

* Quotation and confirmed order scorecards
* Computed conversion rate percentage
* Revenue tracking
* Monthly trend chart
* Salesperson filter

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Install manually or when ``sale`` is present.

Dependencies
============

* ``spreadsheet_dashboard``
* ``sale``

Known issues / Roadmap
======================

* Time-to-conversion analysis
* Lost quote reasons

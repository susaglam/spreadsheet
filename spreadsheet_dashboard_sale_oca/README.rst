Spreadsheet Dashboard for Sales
===============================

|badge1| |badge2| |badge3|

Pre-built sales analytics dashboard.

**Table of contents**

.. contents::
   :local:

Features
========

* 4 KPI scorecards (Revenue, Orders, Quantity Sold, Avg Order Value)
* Monthly revenue trend
* Recent orders list
* Salesperson and product category filters

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Auto-installs when ``sale`` module is present.

Dependencies
============

* ``spreadsheet_dashboard``
* ``sale``

E-commerce Analytics Dashboard
==============================

|badge1| |badge2| |badge3|

Pre-built e-commerce analytics (website revenue, orders, basket size, customers).

**Table of contents**

.. contents::
   :local:

Features
========

* Website-only revenue scorecards
* Daily revenue trend
* Recent orders list
* Auto-filters to website-originated orders

Usage
=====

Auto-installs with ``website_sale``.

Configuration
=============

No configuration needed.

Dependencies
============

* ``spreadsheet_dashboard``
* ``website_sale``

Known issues / Roadmap
======================

* Cart abandonment metrics
* Conversion funnel visualization

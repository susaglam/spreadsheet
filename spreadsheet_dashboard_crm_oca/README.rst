Spreadsheet Dashboard for CRM
=============================

|badge1| |badge2| |badge3|

Pre-built CRM pipeline analytics dashboard.

**Table of contents**

.. contents::
   :local:

Features
========

* 4 KPI scorecards (Opportunities, Expected Revenue, Prorated Revenue, Won)
* Monthly trend chart
* Top opportunities list
* Salesperson and team filters
* Period-over-period comparison

Usage
=====

After installation, the dashboard appears under **Dashboards** (spreadsheet_dashboard app).

Configuration
=============

Auto-installs when ``crm`` module is present.

Dependencies
============

* ``spreadsheet_dashboard``
* ``crm``

Known issues / Roadmap
======================

* Win/loss ratio trend
* Conversion rate by stage

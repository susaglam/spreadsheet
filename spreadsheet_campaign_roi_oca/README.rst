Campaign ROI Dashboard
======================

|badge1| |badge2| |badge3|

Marketing campaign performance tracking (sent/delivered/opened/clicked).

**Table of contents**

.. contents::
   :local:

Features
========

* Campaign performance scorecards
* Monthly delivery trend
* Recent campaigns list

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Auto-installs with ``mass_mailing``.

Dependencies
============

* ``spreadsheet_dashboard``
* ``mass_mailing``

Known issues / Roadmap
======================

* ROI calculation with sale attribution
* Coupon usage tracking

Spreadsheet Dashboard for HR
============================

|badge1| |badge2| |badge3|

Pre-built human resources overview dashboard.

**Table of contents**

.. contents::
   :local:

Features
========

* Employee count scorecards
* Department and job position breakdowns
* Employee directory
* Department and company filters

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Auto-installs when ``hr`` module is present.

Dependencies
============

* ``spreadsheet_dashboard``
* ``hr``

Known issues / Roadmap
======================

* Headcount evolution
* Attendance analytics

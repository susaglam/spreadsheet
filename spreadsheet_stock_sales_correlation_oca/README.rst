Stock-Sales Correlation Dashboard
=================================

|badge1| |badge2| |badge3|

Stock level vs sales velocity analysis for inventory optimization.

**Table of contents**

.. contents::
   :local:

Features
========

* Products in stock vs sold scorecards
* Weekly stock movement trend
* Top moving products list

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Auto-installs with ``sale_stock``.

Dependencies
============

* ``spreadsheet_dashboard``
* ``sale_stock``

Known issues / Roadmap
======================

* Reorder point suggestions
* Seasonal demand patterns

Loyalty Program Dashboard
=========================

|badge1| |badge2| |badge3|

Loyalty program analytics (members, points, top customers).

**Table of contents**

.. contents::
   :local:

Features
========

* Member and points scorecards
* Monthly enrollment trend
* Top members by points

Usage
=====

After installation, the dashboard appears under **Dashboards**.

Configuration
=============

Auto-installs with ``loyalty``.

Dependencies
============

* ``spreadsheet_dashboard``
* ``loyalty``

Known issues / Roadmap
======================

* Points expiry analytics
* Redemption rate tracking

====================================
Spreadsheet Help & Examples
====================================

In-app help center, formula reference, tutorials library, sample data loader,
and interactive tour for the Spreadsheet OCA suite.

Features
========

* Formula reference panel with live examples
* Step-by-step tutorials browsable from the spreadsheet menu
* Sample data loader to spin up demo spreadsheets in one click
* Interactive tour that walks new users through the editor

Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/OCA/spreadsheet/issues>`_.
